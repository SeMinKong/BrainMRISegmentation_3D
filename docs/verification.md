```powershell

npm.cmd run build
```

## 실제 다운로드 파일 점검 — 2026-09-10

로컬 `data/MU-Glioma-Post`의 203개 환자 ID·596개 검사·2,978개 NIfTI를 전수 확인했습니다. 모든 파일의 gzip CRC, 복셀 유한성, 허용 라벨, 사례 내 shape·affine 일치를 통과했습니다. 전체 볼륨은 240×240×155, 1 mm, LPS 방향이며 웹에서 RAS로 정규화할 수 있습니다. 이 검사는 파일 형식·무결성·좌표 호환성에 대한 것으로 모델 성능이나 주석 정확도 검증은 아닙니다.

마스크가 없는 2개 검사를 별도 목록에 기록했습니다. 서로 다른 환자 ID에서 MRI 4종이 동일한 11쌍(22개 검사), 같은 검사에서 T1과 FLAIR 파일이 동일한 1개 검사는 지도 학습 목록에서 제외했습니다. 11쌍 중 3쌍의 마스크는 동일하며 8쌍은 실제 복셀 값이 다름을 확인했습니다. 원인을 추정해 파일이나 라벨을 수정하지 않았습니다.

원본을 보존한 기본 manifest는 571개 검사·200개 환자 ID입니다. 학습 435개/검증 136개로 나누고, 동일 파일로 연결된 환자 ID는 남은 검사도 같은 분할 그룹에 넣었습니다. 분할 간 환자 ID 교차와 확인된 파일 내용 중복은 없습니다. 생성 스크립트의 seed 42 분할 재현과 원본 경로·파일 크기·수정 시각 보존을 독립적으로 확인했습니다.

- 실제 `*_brain_*` MRI 4개와 `*_tumorMask` 1개를 임시 API 저장소에 가져오기: 통과.
- 4개 시퀀스의 축상 단면, 관상·시상 단면, 3D mesh 응답: 통과.
- 다운로드한 마스크와 RAS 정규화된 원본의 복셀 값·affine 완전 일치: 통과.
- 원본 파일명을 지원하는 백엔드·manifest 회귀 테스트를 포함한 Python 테스트: 43개 통과.
