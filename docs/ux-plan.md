# UX 개선 계획 (2026-09-16)

## 사용자와 과업

- **주 사용자**: 의료 지식이 없는 개발자. "내 모델이 처음 보는 환자에서 얼마나 맞고 어디서 틀리는지"를 빨리 파악하려 한다.
- **부 사용자**: 결과를 보여 줄 상대. 설명 없이 색과 숫자의 의미를 이해해야 한다.
- **핵심 과업**: ① 모델 전체 성능 파악 → ② 실패 사례 찾기 → ③ 한 사례에서 왜 틀렸는지 보기.

## 설계 원칙

1. 한 화면 = 한 질문(전체 → 어느 환자 → 왜).
2. 숫자에는 항상 비교 대상(검증 평균, 분포 위치).
3. 틀린 곳은 계산해서 색으로 보여 준다(사용자가 두 그림을 대조하지 않게).
4. 조작은 대상 옆에(3D 버튼은 3D 안, 단면 버튼은 단면 옆).
5. 첫 결과까지 30초: 클릭 2번, 스크롤 0번.

## 검증 시나리오

1. 전체 성능 파악(개요 화면 열기) 2. 가장 나쁜 사례 열기 3. 그 사례에서 놓친 부위 찾기(차이 보기) 4. 다른 시퀀스로 확인 5. 결과 저장. 각 60초 이내, 스크롤 최소를 목표로 하고 결과는 `verification.md`에 기록한다.
